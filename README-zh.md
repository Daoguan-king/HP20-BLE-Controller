[English](README.md) | **简体中文**

## 功能

- 蓝牙扫描 / 连接 / **断线自动重连** / **连接中可取消**（三段式：系统缓存地址 → 直连地址 → 重新扫描）
- 实时监控：**单图双 Y 轴**（左温度、右功率）、鼠标悬停十字准线与读数、X 轴按时间显示
- 加热控制：挡位 T1–T3 选择、自定义目标温度、**开始 / 停止**（停止 = 选 T4 停止通道，与官方 APP 行为一致）
- 回流焊曲线与维修参数读写、设备名读写、**一键恢复出厂默认参数**
- 原始帧控制台（可暂停/恢复自动滚动）+ **诊断面板**：把任意一帧按字节逐段解析（也可从控制台点选历史帧钉住查看）
- CSV 记录（完整 14 列中文表头 / 简洁 3 列）与 **无损 PNG/SVG 折线图导出**
- 输入校验：温度 40–350℃；回流焊/维修各字段范围严格按设备手册

## 环境要求

- Windows 10/11，具备蓝牙 LE 适配器
- Python 3.12+ 与 `bleak`：`pip install bleak`
- 可选：`pillow`（导出 PNG 图表用；缺失时自动降级为 SVG）

## 运行

```powershell
python winapp\atk_hp20.py                        # 图形界面：扫描后选设备连接
python winapp\atk_hp20.py --address AA:BB:CC:DD:EE:FF
python winapp\atk_hp20.py --probe   AA:BB:CC:DD:EE:FF   # 只读自检（退出码 0/1/2）
python winapp\atk_hp20.py --sim                          # 内置模拟设备，无硬件也能体验
python winapp\atk_hp20.py --selftest                     # 44 项端到端自检
python -m unittest discover -s winapp -p "test_*.py"     # 单元测试（462 项）
```

## 打包成免安装 exe

```powershell
powershell -ExecutionPolicy Bypass -File packaging\build.ps1
```

脚本会先跑单测与自检，全绿才打包；产物在 `dist\`：`HP20上位机.exe`（无控制台，双击即用）与 `hp20-cli.exe`（带控制台，排障用）。
参数与打包雷区见 `packaging/README.md`。

## 状态帧字段简表（cmd `0x0A` 应答）

| 偏移 | 含义 |
|---|---|
| `[0:2]` | 当前温度（i16，℃） |
| `[2]` | 供电功率（W） |
| `[3:5]` | 输入电压 ×0.1V |
| `[5]` | 输出状态（`0x00` 待机 / `0x02` 加热模式运行中） |
| `[6]` | 当前输出功率（W） |
| `W1=[7:9]` | `&0x3FF` 目标温度；`>>10&3` 挡位；`>>12&7` 模式（0 待机 / 1 回流焊 / 2 加热 / 3 设置 / 4 维修 / 8 主页） |
| `W2=[9:11]` | 加热计时，**64 进制打包的 MM:SS**（每分钟 64 个单位）；`0x29BF` 表示未启用 |

## 已知限制

- 面板上的**风扇 1–5 档不上报**，协议里读不到（界面显示「不可读」）；
- **加热超时、温度微调、电源功率、蜂鸣、背光、休眠** 等设置项不经蓝牙，只能在面板修改；
- 协议里**没有**「启动回流焊 / 启动维修」命令（只能写参数），启动需在面板操作；「停止」可用 T4 停止通道；
- 停止加热不等于切换运行模式（`mode` 仍为 2）；物理面板按钮始终是最后保障。
